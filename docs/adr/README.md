# Architecture Decision Records

Short records of decisions that shape the code, written when the decision is
made. Copy [0000-template.md](0000-template.md) to start a new one.

An accepted ADR is not edited to change its decision. If the decision changes,
write a new ADR that supersedes it and update the old one's status.
