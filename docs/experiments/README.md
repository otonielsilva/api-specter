# Experiment reports

One report per experiment, named `NNN-short-title.md`. A report is written
whether the result is positive, negative or inconclusive. Negative results
are results.

## Template

```markdown
# NNN. Title

- Date: YYYY-MM-DD
- Commit: <sha>

## Question
What are we trying to find out?

## Hypothesis
What we expect, and why, written before running anything.

## Setup
Target (zoo bugs enabled), specter config, seeds, request budget, machine.
Enough detail to rerun it.

## Results
Numbers and graphs. Raw data or the command that produces it.

## Conclusion
What the data supports, what it doesn't, and what to try next.
```
